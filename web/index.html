FRED — live demo

FRED is an AI analyst. Ask it about a synthetic e-commerce company and it resolves your wording to a governed metric, compiles SQL, runs it, and shows its work. The whole engine — semantic layer, SQL compiler, validator, DuckDB — runs in this tab via WebAssembly. No server, no API key, nothing sent anywhere.
